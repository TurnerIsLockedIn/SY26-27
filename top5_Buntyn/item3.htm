#3: The Finals

The Finals is on my list because the movement is incredibly fast and fluid. The fact that you can blow up entire buildings completely changes how you capture objectives. It feels like a chaotic game show, and the fast-paced action keeps me hooked for hours.

  • It is a free-to-play shooter developed by Embark Studios.
  • The game matches teams in a virtual combat game show arena.
  • It features fully destructible environments running on server-side physics.
